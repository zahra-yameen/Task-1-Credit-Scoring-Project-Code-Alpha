# Task-1-Credit-Scoring-Project-Code-Alpha
A Machine Learning-based Credit Scoring Model that predicts credit risk using financial data. Implements Logistic Regression, Decision Tree, and Random Forest algorithms and evaluates performance using Precision, Recall, F1-score, and ROC-AUC. Includes a Streamlit web app for interactive predictions.


# Credit Scoring Model Using Machine Learning

## Overview
An educational machine learning project that classifies
historical credit-risk categories using applicant data.

## Objective
Predict good or bad historical credit risk using supervised
classification algorithms.

## Dataset
German Credit Risk dataset from Kaggle.

## Algorithms
- Logistic Regression
- Decision Tree
- Random Forest

## Features
- Age
- Housing
- Saving accounts
- Checking account
- Credit amount
- Duration
- Purpose
- Monthly credit amount proxy

## Evaluation
Accuracy, precision, recall, F1-score, ROC-AUC,
classification report, and confusion matrix.

## Technology
Python, pandas, scikit-learn, Matplotlib, Seaborn,
joblib, and Streamlit.

## Run the project

Install the dependencies:

    pip install -r requirements.txt

Train the models:

    python train_model.py

Launch the application:

    python -m streamlit run app.py

## Limitations
This project uses a small historical dataset and is for
learning purposes. It is not an official credit score and
must not be used to make actual lending decisions.
